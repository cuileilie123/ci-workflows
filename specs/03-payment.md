# 需求规格：支付与钱包

## 1. 微信支付流程
- 下单 → 后端调微信 V3 统一下单 → 返回预支付参数
- 前端调 `wx.requestPayment` 拉起支付
- 后端接收异步回调 `/pay/notify`，验签
- 更新订单状态为 PAID，写入钱包流水

## 2. 钱包体系（复式记账）
- 每个用户一个钱包（Wallet）
- 每笔变动记录 Transaction（INCOME/EXPENSE/FREEZE/UNFREEZE）
- `balance_after` 记录变动后余额，用于对账
- 冻结金额：任务进行中冻结，完成后结算

## 3. 平台抽成
- 默认费率 10%，可配置
- 计算公式：`platform_fee = total_amount * 0.10`
- 抽成在订单完成时结算

## 4. 提现
- 调用微信企业付款到零钱
- 最低提现 1 元，单笔最高 5000 元
- T+1 到账
- 大额提现（>1000）触发人工审核

## 5. 退款
- 未接单状态：全额退款
- 进行中：协商退款，平台仲裁
- 已结算：不支持退款
- 退款到账时间：原路退回，1-3 个工作日
