# 静态资源说明

## 需要准备的图片资源

### 1. 地图标记图标
- `marker.png` - 地图标记点图标（建议尺寸：32x32px）

### 2. TabBar 图标（放在 tabbar/ 目录下）
每个图标需要准备两种状态：默认状态和选中状态

| 文件名 | 说明 | 建议尺寸 |
|--------|------|----------|
| `home.png` | 首页图标（未选中） | 81x81px |
| `home-active.png` | 首页图标（选中） | 81x81px |
| `task.png` | 任务图标（未选中） | 81x81px |
| `task-active.png` | 任务图标（选中） | 81x81px |
| `chat.png` | 消息图标（未选中） | 81x81px |
| `chat-active.png` | 消息图标（选中） | 81x81px |
| `profile.png` | 我的图标（未选中） | 81x81px |
| `profile-active.png` | 我的图标（选中） | 81x81px |

### 图标设计要求
- 格式：PNG（支持透明背景）
- 颜色：
  - 未选中状态：#7A7E83（灰色）
  - 选中状态：#4CAF50（绿色，与主题色一致）
- 风格：简洁线性图标

### 临时解决方案
在正式图标准备好之前，可以使用以下临时方案：
1. 使用 emoji 或 unicode 符号作为临时图标
2. 使用在线图标生成工具（如 IconFont、Flaticon）
3. 联系设计师提供专业图标
