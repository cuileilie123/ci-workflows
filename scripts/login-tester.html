🔑 微信登录测试器

从微信开发者工具获取真实 code，粘贴到此处完成登录

1获取微信 code
在微信开发者工具中：
  1. 打开微信开发者工具，导入你的小程序项目
  2. 在 Console 面板执行：wx.login({ success: res => console.log("CODE:", res.code) })
  3. 复制打印出的 code 值（5 分钟内有效）
或在小程序代码中： const res = await wx.login(); console.log("CODE:", res.code);
2输入 code 并登录
3登录结果
📋 Access Token（复制后可在 Swagger 中使用）
